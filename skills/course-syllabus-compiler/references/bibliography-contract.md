# 教材与学习资料合同

## 选用教材

只填写整本教材的标准书目信息，不在书目后追加“课程使用第1—6章”“课程使用第7—10章”等范围说明。章节范围进入教学内容。

格式：`作者. 书名（版次）[M]. 出版地：出版社，出版年. ISBN 号码`

**ISBN 后直接结束，不加中文句号、英文句号或其他标点。**

正确示例：

`戴波. C与C++程序设计（第二版）[M]. 北京：北京大学出版社，2025. ISBN 9787301362648`

不得写“课程使用第……”或 `ISBN 9787301362648。`。

## 学习资料

优先列与课程直接相关、由中国大陆正式出版社出版、原则上近5年的教材或教学参考书。用户未提供时，先从出版社官网或其他可靠出版信息源核对书名、作者、版次、出版社、年份和 ISBN；无法核验则少列，**不得编造**。

Visual Studio Code、在线 OJ、教师案例、讲义和软件环境说明属于教学资源，不作为正式“学习资料”书目凑数。

# 大纲直接编制合同

本 Skill 是课程大纲作者和编译器。上游出现“课程目标待编制”“考核方案待编制”时，应根据已确认的培养方案、教材范围、课程关系和教学逻辑直接形成可逐字人工审核的完整初稿，不把“待编制”带入正式正文。

正式大纲不出现 official、derived、proposal、source_id、AI 生成说明、候选、建议值或内部审查状态。课程事实与来源冲突时先指出冲突，不能静默用模型常识替换培养方案。

Markdown 只表达语义；Word 的列数、合并、字号、列宽和分页由确定性 renderer 与 `school-layout-contract.yaml` 决定。

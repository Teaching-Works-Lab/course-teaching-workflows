# Word / WPS 兼容合同

- A4 纵向，页边距约 25 mm，页码位于页脚中部。
- 中文正文宋体、标题黑体、西文 Times New Roman；最终 DOCX 不写 Linux 专用 Noto 字体。
- `w:tblGrid/w:gridCol/@w:w` 使用 twip，禁止把 python-docx 的 EMU 整数直接写入 OOXML 宽度字段。
- 多页表格重复表头；重要长行尽量不拆页；避免 exact 行距造成字体替换后重叠。
- 最终文件不得包含批注、修订、隐藏文字、AI/模型署名、未解决占位符或生成工具元数据。
- 生成器或模板变化时必须渲染全页检查；日常内容更新仍需至少执行结构和清洁检查。
